Номер продукта лежит в `VERSION`. Закрытая работа поднимает patch. Minor и major человек ставит вручную. Контракт HTTP остаётся `/v1`, пока его не ломают: новая возможность не заводит `/v2`.

## 0.1.7

- В строке журнала лежит время запроса, `request_time_ms`. Модуль отдаёт его из nginx. Демон читает `$request_time` в строке nginx и `Duration` в журнале прокси. Ноль значит, что сборщик время не прислал. Совет по пути этим полем ещё не строится.
- Сборщик Coolify читает журнал прокси и сдаёт ту же пачку. Запрос не меняется. Один процесс на сервер, каждый домен становится сайтом.
- Хост — это весь вебсервер. Запрос к имени или пути, которого нет, остаётся в журнале: так виден скан.
- Пользователь на Overview и Requests видит запросы своих хостов, без адресов.
- Чтение журнала больше не падает: запрос в ClickHouse уходит POST.
- Админ на Overview видит карту стран, общий RPS и RPS каждого домена за последнюю минуту.
- Админ видит адреса, которые стучались. У адреса кнопка Actions: детали, запросы и копия. Block и challenge видны и выключены: наблюдение запрос не останавливает.
- Таблицы журнала листаются курсором. На странице 500 строк, кнопки Prev и Next.
- На главной образец кабинета: карточки, зонды и карта стран. Живого журнала на сайте нет.
- Сайдбар кабинета: щит, плашка записи и пункты с отметкой выбранного. В плашке запросы, зонды и RPS за то, что уже есть в журнале.
- Смена раздела кабинета показывает радар Threatrix, пока экран открывается.
- Overview обновляется раз в секунду. Новый запрос вспыхивает зелёным и возвращается к обычному цвету. Интервал: 1, 5, 10, 30, 60 или Never.
- Зонды, запросы и сайты — отдельные живые страницы того же журнала. Путь зонда и медленный путь открывают запросы этого пути. У сайта за сутки видны запросы и зонды, за минуту RPS. Край виден админу. В строке запроса видно время, если сборщик его прислал. Requests и Addresses обновляются тем же интервалом, пока открыта первая страница.

## 0.1.6

- Мастер после установки ждёт первый сайт и закрывается, когда имя пришло.
- Демон Linux читает журнал nginx и сдаёт ту же пачку. Запрос и блокировка nginx не меняются.
- Агент носит номер из `VERSION`. Пачка называет сборку, кабинет показывает номер, который пришёл с хоста.

## 0.1.5

- Кнопка Add host есть у пользователя на dash. Хост принадлежит ему. Админ видит хосты всех.
- Сценарий API идёт через service, чтение и запись — через repository. Маршрут принимает запрос и отдаёт ответ.
- В сайдбаре кабинета виден номер из `VERSION`.
- Хост можно удалить. Журнал этого хоста остаётся. Строка живёт 3 года.
- Админ при добавлении хоста привязывает его к пользователю. Пользователь по-прежнему получает хост себе. Строки установки модуля видит он, в своём кабинете.
- Код ошибки живёт константой: в API `app/codes.py`, в кабинете `shared/lib/api-error.ts`.

## 0.1.4

- Админ добавляет хост мастером: имя, способ сдачи, установка nginx. DNS, демон и Apache в выборе есть и пока недоступны.
- Сайт на хосте появляется из имени Host в пачке. Выключенный сайт больше не пишется.
- Страна запроса берётся при приёме из локальной базы GeoIP. Без файла код пустой. Карты нет.

## 0.1.3

- Кабинеты разведены по хостам. `dash.ledgesec.com` — клиент, `admin.ledgesec.com` — админ.
- Оболочка обоих — тёмная тема Threatrix в том же Next.js. Демо-экраны шаблона не подключены.
- Вход проверяет email и пароль схемой Zod до запроса. Текст ошибки не меняет высоту карточки.

## 0.1.2

- Клиент наблюдения для OpenResty: `log_by_lua` кладёт короткую запись в `lua_shared_dict`, таймер шлёт `POST https://dash.ledgesec.com/api/v1/observations` с `X-Ledgesec-Mac`.
- Зонд и ответ от 400 уходят всегда, остальное — 1%. Список зондов собран из `classify()`.
- При ошибке приёма пачка остаётся в кольце. Тело, Cookie, query, Authorization и Referer не пишутся.

## 0.1.1

- Пароль Postgres с пробелом доходит до SQLAlchemy. Раньше пробел становился `+` в URL, вход в базу не проходил, API не становился healthy и Caddy не поднимал 80/443.

## 0.1.0

Первая помеченная версия. До неё коммиты шли в main без номера.

- Сайт, блог и вход на dash в одном приложении Next.js.
- Сессия одна на админа и пользователя сайта. Админ — строка в Postgres, при старте не создаётся.
- API на FastAPI и Pydantic. Схема Postgres — Alembic. Журнал — ClickHouse своим клиентом.
- Приём пачки по HMAC, метка зонда при чтении, сводка за 24 часа.
