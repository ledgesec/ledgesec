# Changelog

Номер продукта лежит в `VERSION`. Закрытая работа поднимает patch. Minor и major человек ставит вручную. Контракт HTTP остаётся `/v1`, пока его не ломают: новая возможность не заводит `/v2`.

## Unreleased

## 0.1.3

- Кабинеты разведены по хостам. `dash.ledgesec.com` — клиент, `admin.ledgesec.com` — админ.
- Оболочка обоих — тёмная тема Threatrix в том же Next.js. Демо-экраны шаблона не подключены.
- Вход проверяет email и пароль схемой Zod до запроса. Текст ошибки не меняет высоту карточки.

## 0.1.2

- Клиент наблюдения для OpenResty: `log_by_lua` кладёт короткую запись в `lua_shared_dict`, таймер шлёт `POST https://dash.ledgesec.com/api/v1/observations` с `X-Ledgesec-Mac`.
- Зонд и ответ от 400 уходят всегда, остальное — 1%. Список зондов собран из `classify()`.
- При ошибке приёма пачка остаётся в кольце. Тело, Cookie, query, Authorization и Referer не пишутся.

## 0.1.1

- Пароль Postgres с пробелом доходит до SQLAlchemy. Раньше пробел становился `+` в URL, вход в базу не проходил, API не становился healthy и Caddy не поднимал 80/443.

## 0.1.0

Первая помеченная версия. До неё коммиты шли в main без номера.

- Сайт, блог и вход на dash в одном приложении Next.js.
- Сессия одна на админа и пользователя сайта. Админ — строка в Postgres, при старте не создаётся.
- API на FastAPI и Pydantic. Схема Postgres — Alembic. Журнал — ClickHouse своим клиентом.
- Приём пачки по HMAC, метка зонда при чтении, сводка за 24 часа.
