# API

Контейнер `api` в общей сети compose. Снаружи его не публикуют: край проксирует `/api/` только с `dash.ledgesec.com`. Браузер в Postgres и ClickHouse не ходит.

`GET /health` проверяет обе базы и пишет `ingest: ok`, только если секрет приёма задан. Само значение не отдаёт. `POST /v1/observations` принимает пачку от модуля, если заголовок `X-Ledgesec-Mac` совпал с `LEDGESEC_INGEST_SECRET`.

Остальные чтения требуют сессию. Админ видит адреса. Пользователь сайта видит свои пути без адресов. Метка зонда считается при чтении, в журнал она отдельно не пишется.
