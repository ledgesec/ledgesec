# API

Учёт пользователей и сайтов, выпуск и продление сертификата, раздача снимка, чтение журнала для кабинета. Браузер в ClickHouse не ходит, только сюда.

Postgres хранит пользователей, сайты и состояние сертификата. ClickHouse хранит события. Вставка в журнал идёт пачкой из sidecar, не с воркера nginx.

На путь запроса посетителя API не встаёт. Кода здесь ещё нет.
