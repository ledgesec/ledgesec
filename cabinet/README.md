# Кабинет

Один frontend. Роль берётся из сессии: владелец платформы видит все сайты, заказчик только свои.

В v1 заказчик добавляет сайт: домен и origin. Кабинет показывает две A-записи краёв, ждёт, что они смотрят на нас, и выпускает сертификат. Сайт начинает в сухом прогоне. Включение мер отдельным шагом.

Шаг «поставить пакет на свой сервер» в этот поток не входит. Кода кабинета здесь ещё нет.
