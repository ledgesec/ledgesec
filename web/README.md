# Сайт и дашборд

Одно приложение Next.js. Тема в `src/app/globals.css`: бумажный фон, наборный заголовок, ржавая метка зонда. Компоненты shadcn.

```bash
npm run dev
```

Сайт: http://127.0.0.1:44733/  
Дашборд: http://127.0.0.1:44733/dashboard

Превью входа: `admin@ledgesec.com` видит адреса, `iris@example.com` видит один сайт без адресов. Любой пароль. Это не боевой API.
