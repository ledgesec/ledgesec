# Край

OpenResty в контейнере `edge`. На европейской машине он один слушает 80 и 443 и отдаёт кабинет и `/api/` внутрь сети compose. Пока своего сертификата нет, контейнер занимает 443 временным сертификатом на два дня, чтобы порт не забрал другой процесс. Боевой сертификат кладётся в том `edge_certs`.

Нью-йоркский край тем же образом, без Postgres и без ClickHouse, и не через панель Coolify.
