# Край

OpenResty на двух серверах. Европейский держит ещё кабинет, Postgres и ClickHouse. Нью-йоркский только край. Порт 443 на обеих машинах принадлежит OpenResty.

Посетитель резолвит домен заказчика в два адреса края. Край терминирует TLS, применяет снимок и на origin пускает только то, что решил пустить. Origin принимает веб только с адресов края.

Снимок край забирает каждые 5–10 секунд. На запросе нет похода в ClickHouse, в DNS и в sidecar. Три меры: заглушка, если адрес уже подозрительный; временный запрет, если ведро полное; WAF, если этот запрос атака.

Кода края здесь ещё нет. Это следующая сборка.
