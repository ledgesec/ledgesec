# Край

Caddy в контейнере `edge`. На европейской машине он один слушает 80 и 443, сам выпускает сертификат для `ledgesec.com` и `www`, и отдаёт кабинет и `/api/` внутрь сети compose.

Нью-йоркский край — `docker-compose.us.yml`. В нём нет Postgres, ClickHouse, кабинета и API, и он не ставится через Coolify. Слушает 80 и 443, сертификат для `us.ledgesec.com`. Пока фильтра нет, на `/` отвечает, что это край US East.

На серверах не задавай `CADDY_LOCAL_CERTS`. Эта переменная только для локального запуска, где публичный порт 80 недоступен.
